## 🌐 Access the Web Application

### 1️⃣ Find Your WSL IP Address

Run the following command:

```bash
ip addr show eth0 | grep inet
```

Example output:

```text
inet 172.17.185.124/20
```

Open your browser and visit:

```text
http://YOUR_WSL_IP:3000
```

Example:

```text
http://172.17.185.124:3000
```

> **Note:** Replace `YOUR_WSL_IP` with the IP address assigned to your WSL instance.

---

# 🔗 Configure MetaMask for Hardhat Local Network

## Step 1 — Add a Custom Network

Open **MetaMask** and add a new network using the following settings:

| Setting | Value |
|---------|-------|
| **Network Name** | Hardhat Local |
| **RPC URL** | `http://YOUR_WSL_IP:8545` |
| **Chain ID** | `1337` |
| **Currency Symbol** | ETH |

Example:

```text
RPC URL:
http://172.17.185.124:8545
```

> ⚠️ Replace `YOUR_WSL_IP` with your actual WSL IP address.

---

## Step 2 — Import a Hardhat Account

After starting the Hardhat node, import **Account #0** into MetaMask using the following private key:

```text
0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae78xxxxxxxxxxxxxxx
```

### Import Steps

1. Open **MetaMask**
2. Click your **Profile** icon
3. Select **Import Account**
4. Paste the private key above
5. Click **Import**

---

## Step 3 — Connect to the DApp

Open the application in your browser:

```text
http://YOUR_WSL_IP:3000
```

Then:

1. Click **Connect Wallet**
2. Select the imported Hardhat account
3. Approve the MetaMask connection
4. Start interacting with the smart contract 🎉
