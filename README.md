### 📁 Directory Overview

| Directory | Description |
|------------|-------------|
| `contracts/` | Solidity smart contracts for the Ethereum blockchain. |
| `scripts/` | Deployment and interaction scripts using Hardhat. |
| `test/` | Automated smart contract test suite. |
| `frontend/` | Web-based decentralized application (DApp) interface. |
| `frontend/assets/` | Static assets including images and icons. |
| `frontend/abi/` | Contract ABI files used by the frontend. |
| `artifacts/` | Compiled contract artifacts generated by Hardhat. |
| `cache/` | Hardhat build cache. |
| `ignition/` | Hardhat Ignition deployment modules. |
| `docs/` | Project documentation, architecture, and screenshots. |
| `.github/` | GitHub Actions workflows, issue templates, and repository configuration. |
